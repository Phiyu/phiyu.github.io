# Yu's Academic Homepage

This repository hosts the personal academic homepage of **Kevin Yu**, an undergraduate student in astronomy at the **University of Science and Technology of China (USTC)**.

🌐 View the live site at: [https://phiyu.github.io](https://phiyu.github.io)

---

## ✨ Features

- Minimal, responsive design built on the [Minimal Mistakes](https://github.com/mmistakes/minimal-mistakes) Jekyll theme
- Academic profile with sections for:
  - Research Experience
  - Honors & Publications
  - Teaching Resources (TA Archive)
  - CV download
- Custom navigation bar
- Ready for custom domain deployment

---

## 📁 Directory Structure

- `_posts/` – Blog articles
- `_pages/` – Custom pages (CV, Research, Teaching, etc.)
- `assets/` – Images, CSS, and JS files
- `_data/navigation.yml` – Menu structure
- `CNAME` – Custom domain support
